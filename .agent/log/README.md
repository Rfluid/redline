# Session log

One file per working session: `YYYY-MM-DD-<short-slug>.md`. Newest is the handoff to the next agent.

Template:

```markdown
# <date> · <slug>

**Agent:** <claude/codex/…>  **Roadmap:** <task IDs>

## Done
- <what changed, files>

## Verified
- <just check result, manual checks>

## Open / next
- <loose ends, follow-ups added to ROADMAP>

## Gotchas
- <anything that cost time; promote to a workflow if it will recur>
```
